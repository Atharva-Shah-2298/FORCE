# Out-of-sample angular resolution and fiber-number

Repeats the synthetic angular-resolution and fiber-number experiments
(`../synthetic_angle_accuracy`) on out-of-sample data. The test crossings are
generated by Monte Carlo simulation of restricted and hindered diffusion in
packed cylinders, so their signals lie outside the forward model of every method
compared (FORCE, CSA, CSD, GQI, ODF-FP); the comparison is therefore not an
inverse crime.

## Requirements

The comparison spans three tools that cannot share a single Python environment,
so each stage is run in its own environment:

1. **Monte Carlo phantom** — [disimpy](https://github.com/kerkelae/disimpy), a
   GPU random-walk diffusion simulator; requires a CUDA GPU. Reuses the
   packed-cylinder substrate from `../mc_phantom`.
2. **FORCE and the inverse methods** — a recent DIPY that includes the FORCE
   model; the same install provides CSA, CSD and GQI.
3. **ODF-FP** — the original implementation from DIPY pull request #2962
   ([filipp02/dipy_odffp](https://github.com/filipp02/dipy_odffp)). It targets an
   earlier DIPY and is kept separate; `run_odffp_pr.py` and `run_odffp_nufo.py`
   load it directly and supply the small `dsi_sphere` helper it expects.

## Pipeline

Phantoms: `gen_crossings.py` (two-fiber crossings, angle sweep), `gen_nufo.py`
(one/two/three-fiber voxels).
Fits: `fit_and_score.py` and `fit_force_crossings_alpha.py` (FORCE),
`fit_nufo.py` (FORCE and inverse, fiber count), `run_inverse.py` (CSA/CSD/GQI),
`run_odffp_pr.py` and `run_odffp_nufo.py` (ODF-FP).
Scoring: `score_all.py` (angular resolution), `nufo_fig.py` (fiber count).

Detected peaks are amplitude-pruned (0.5 x max) and matched one-to-one to the two
true fiber axes within 20 deg; a crossing counts as resolved when both are
recovered. Inverse-method peak detection uses a 25 deg (or 45 deg) minimum
separation. Generated data (`*.npz`) is git-ignored.
