# Out-of-sample angular resolution and fiber-number

Repeats the synthetic angular-resolution and fiber-number experiments on
out-of-sample crossings generated by Monte Carlo simulation of restricted and
hindered diffusion in packed cylinders (disimpy), so the test signals lie outside
the forward model of every method compared (FORCE, CSA, CSD, GQI, ODF-FP).

## Environments
- `skyline`: disimpy GPU phantom generation (reuses `../mc_phantom` kernels).
- `dipy-min-angle/.venv`: FORCE + CSA/CSD/GQI.
- `odffp-build2`: original ODF-FP (PR #2962), loaded from a `pr/filipp02/2962`
  worktree with the `dsi_sphere` module shimmed in.

## Pipeline
Phantoms: `gen_crossings.py` (two-fiber, angle sweep), `gen_nufo.py` (1/2/3 fiber).
Fits: `fit_and_score.py` and `fit_force_crossings_alpha.py` (FORCE crossings),
`fit_nufo.py` (FORCE + inverse, fiber count), `run_inverse.py` (CSA/CSD/GQI peaks),
`run_odffp_pr.py` / `run_odffp_nufo.py` (ODF-FP).
Scoring/printing: `score_all.py` (angular resolution), `nufo_fig.py` (fiber count).

Peaks are amplitude-pruned (0.5x max) and matched 1-to-1 to the true axes within
20 deg; inverse-method peak detection uses a 25 deg (or 45 deg) minimum separation.
Data (`*.npz`) is git-ignored.
